# GitHub Actions demo

This repository includes the GitHub Actions Quickstart workflow from the official docs.

- Workflow path: `.github/workflows/github-actions-demo.yml`
- Trigger: `push` to any branch

How to run locally:
1. Commit and push these files to a GitHub repository.
2. Open the repository on GitHub -> Actions tab -> select "GitHub Actions Demo" to view runs.

That's it — pushing any change will trigger the demo workflow and list files in the runner workspace.
